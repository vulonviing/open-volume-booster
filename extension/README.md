# Installing Open Volume Booster (unpacked)

This folder is a complete, loadable Chromium MV3 extension. No build step —
load it as-is.

## Install

1. Open `chrome://extensions` (Chrome/Edge/Brave) or `dia://extensions` (Dia).
2. Turn on **Developer mode** (top-right toggle).
3. Click **Load unpacked**.
4. Select this `extension/` folder (the one containing `manifest.json`).
5. Pin the icon (puzzle-piece icon → pin) if you want it always visible.

## Updating after pulling changes

Chromium doesn't auto-reload unpacked extensions. After `git pull`:

1. Go back to `chrome://extensions`.
2. Click the **reload icon** on the Open Volume Booster card.

If `manifest.json` permissions changed, the browser will show a warning
and may briefly disable the extension until you re-approve it — that's
expected and is Chromium correctly telling you a permission changed.

## Removing it

Click **Remove** on the extension's card in `chrome://extensions`. Nothing
is stored outside `chrome.storage.local` for this extension, so removal
leaves no other trace.

## Regenerating icons

Icons live in `icons/` and are generated by `../tools/generate-icons.py`
(requires Pillow: `pip install pillow`). Re-run it after editing that
script:

```bash
python3 ../tools/generate-icons.py
```

See the repo root [`README.md`](../README.md) for what the extension does
and why it's built the way it is, and [`AGENTS.md`](../AGENTS.md) for the
invariants any change here must preserve.
